# 요일 표기 → 회차 표기 설계

작성일: 2026-08-12
선행: `2026-08-11-ultraman-progress-design.md` (배포 완료, 태그 `v2-progress`)

## 1. 배경

스케줄을 달력에서 36세션 순번 큐로 바꿨는데(선행 설계 5절), 화면 문구는 여전히 요일로 되어 있다.

"3주차 수요일"은 앱이 지키지 않는 약속이다. 앱에는 "오늘"이 없고, 실제 수요일에 해야 할 이유도 없으며, 화요일을 건너뛰고 수요일을 먼저 해도 아무 문제가 없다. 요일 표기는 사용자에게 존재하지 않는 일정을 암시한다.

## 2. 목표

화면에서 요일을 없애고 **주차 + 회차**로 부른다. `3주차 3회차`.

주차는 남긴다. 중량이 주차 단위로 오르는 선형 주기화이므로 주차는 실제 의미가 있다.

## 3. 비목표

- 데이터 구조 변경. `PARTS`·`WEEKS.days`의 `"월"`~`"토"` 키와 `sessionIndex(w, day)` 시그니처는 그대로 둔다. 이 키들은 슬롯 식별자일 뿐 화면에 나오지 않으면 그만이다.
- 저장 스키마 변경. `done`은 이미 요일이 아니라 순번(`"0"`~`"35"`)으로 기록하므로 **마이그레이션이 필요 없다.**
- 세션 총수·순서·성취율 정의 변경.

## 4. 표기 규칙

`회차 = TRAINING_DAYS.indexOf(day) + 1` → 1–6

| 위치 | 현재 | 변경 |
|---|---|---|
| 홈 다음 훈련 카드 (`sessionLabel`) | `3주차 수요일 · 하체후면/팔` | `3주차 3회차 · 하체후면/팔` |
| 홈 밀린 훈련 목록 | 동일 (`sessionLabel` 공유) | 동일 |
| 홈 히어로 문구 | `주 6일 · 일요일 휴식. 1주차는…` | `한 주 6회차 · 순서대로 진행한다. 1주차는…` |
| 주차 화면 목록 | 7행(일 휴식 + 월~토), 배지에 요일 글자 | **6행**, 배지에 `1`~`6` |
| 상세 화면 헤더 | `WEEK 3 · 수요일` | `WEEK 3 · 3회차` |
| 상세 화면 하단 이동 | `← 화요일` / `목요일 →` | `← 2회차` / `4회차 →` |

## 5. 일요일 휴식 행 제거

주차 화면의 일요일 행을 없앤다. 달력을 쓰지 않으므로 고정된 휴식일이라는 개념 자체가 없다 — 쉬고 싶을 때 쉬면 되고, 그래도 큐는 제자리에 머문다. 부를 이름도 없다.

부수 정리:
- `assets/app.js`의 `DAYS`(7개, 일요일 포함) 상수를 제거하고 `logic.js`의 `TRAINING_DAYS`(6개)를 import해 쓴다.
- `index.html`의 `.day.rest` 관련 규칙 2개를 제거한다(사용처 소멸).
- `data.js`의 `PARTS["일"]`은 남긴다. 데이터 정의일 뿐이고 지우면 `Object.keys(PARTS).length`를 확인하는 기존 검증이 흔들린다.

## 6. 경계 조건 — 이 변경의 유일한 실질 위험

앞뒤 이동(`vDay` 하단 페이저)과 좌우 스와이프가 현재 `DAYS`를 쓰면서 일요일이 인덱스 0에 있다는 전제로 경계를 잡고 있다.

```js
const di = DAYS.indexOf(d);
const prev = di > 1 ? DAYS[di - 1] : null;    // 1 = 월요일
const next = di < 6 ? DAYS[di + 1] : null;    // 6 = 토요일
```

`TRAINING_DAYS`(월=0 … 토=5)로 바꾸면 경계도 함께 바뀌어야 한다.

```js
const di = TRAINING_DAYS.indexOf(d);
const prev = di > 0 ? TRAINING_DAYS[di - 1] : null;
const next = di < 5 ? TRAINING_DAYS[di + 1] : null;
```

같은 전제가 `bindSwipe`에도 복제되어 있다(`i < 6`, `i > 1`). **두 곳을 함께 고쳐야 한다.**

놓치면 1회차에서 이전 버튼이 비활성화되지 않거나 6회차에서 다음으로 넘어가려다 `undefined` 슬롯을 밀어 넣는다. 화면이 조용히 비거나 잘못된 세션이 열린다. 이 변경에서 유일하게 런타임에만 드러나는 결함이므로 검증에서 명시적으로 다룬다.

## 7. 검증

- `node --test` — 기존 28개 통과. `logic.js`는 변경하지 않으므로 새 테스트는 없다.
- 헤드리스 Chrome으로 확인:
  - 주차 화면이 6행이며 배지가 `1`–`6`인지, 휴식 행이 없는지
  - 1회차에서 이전 버튼이 비활성, 6회차에서 다음 버튼이 비활성인지
  - 1회차에서 오른쪽 스와이프, 6회차에서 왼쪽 스와이프가 아무 일도 하지 않는지
  - 화면 어디에도 `요일`·`월`~`일` 문자열이 남아 있지 않은지 (전체 텍스트 스캔)
  - 완료 기록이 변경 전후로 그대로 읽히는지 (스키마 무변경 확인)
